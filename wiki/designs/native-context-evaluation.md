# Native context contract evaluation

The [portable result artifact](../../Benchmarks/native-context-2026-10-20.json)
was generated by actual native paths in
[NativeContextEvaluationTests](../../Tests/TagKitTests/NativeContextEvaluationTests.swift)
and [its cases](../../Tests/TagKitTests/NativeContextEvaluationCases.swift).
Fixture revision 1 uses isolated databases, scripted model replies and local
processes. It makes no paid provider calls. Reproduce from the same source:

```sh
env -u TAG_PROMPT_JOB TAG_CONTEXT_EVAL_REPORT=Benchmarks/native-context-2026-10-20.json \
  swift test --filter NativeContextEvaluationTests
```

## Results

All recorded contract checks passed. Byte columns describe different inputs
per row; they are not combined into a compression percentage.

| Case | Source bytes | Baseline bytes | Native presented bytes |
| --- | ---: | ---: | ---: |
| large_tail_failure | 1,260,014 | 1,049 | 917 |
| whole_input_aggregate | 48,894 | 141 | 323 |
| shared_group_budget | 60,000 | 60,000 | 22,775 |
| explicit_request_projection | 34,120 | 34,120 | 23,674 |
| unicode_and_scope | 9 | 9 | 6 |
| partial_capture_and_recovery | 16 | 16 | 16 |

- **Tail failure:** actual awk output exceeds 1 MB and exits 7. The historical
  first-50-lines baseline misses the tail marker; native search retrieves it
  with a bounded initial reply and preserves failure/completeness.
- **Whole input:** the first 50 numeric lines sum to 1,275. analyze_output
  receives all 10,000 lines and returns 50,005,000. The baseline byte count
  is the sparse stdin, while the native count is its JSON result envelope;
  comparing these does not measure equivalent work or savings.
- **Shared group:** five actual Agent tool results contain 60,000 raw bytes.
  Their model-facing contents share the 32,768-byte budget; all five exact
  artifacts remain available. This excludes tool-schema and message overhead.
- **Projection:** paired Anthropic message JSON over the same canonical
  journal is smaller after explicit compaction. All users remain pinned and
  original entries are unchanged. This is serialized request bytes, not tokens.
- **Unicode/scope:** pagination preserves scalar boundaries and embedded NUL;
  a foreign-session lookup is rejected. The presented range intentionally
  covers six of nine bytes and provides continuation offsets.
- **Partial/recovery:** incomplete evidence stays incomplete; doctor separates
  an interrupted inference from corruption and does not modify or replay it.

Generated IDs/timestamps can change reply values while fixed-width encodings
keep these fixture volumes stable. Source revisions can change them; regenerate
instead of treating the artifact as a permanent performance threshold.

## Broader validation and limits

The full repository gate also covers quota/timeout/cancellation, process-group
teardown, redirects, active-session scope, source integrity, FTS fallback,
exact reads, ordered effects, failure-after-effect recovery and provider replay.
[Diagnostics tests](../../Tests/SessionKitTests/ContextDiagnosticsTests.swift)
check corruption and missing derived data without repairs.
[Terminal tests](../../Tests/TagKitTests/ContextDiagnosticsToolTests.swift)
type local commands at widths 44, 80 and 120; this is rendered Stipple output,
not a claim about every physical terminal or manual visual review.

These fixtures establish implementation contracts and demonstrate why
truncation and sparse search cannot replace retained evidence or full-input
computation. They do not estimate LLM task success, retrieval recall over an
unseen corpus, cache hit rates, billed tokens, cost or production latency.
The [research](native-context-management.md) recommends paired real-task quality
and cache-aware provider evaluation before making those broader claims.
