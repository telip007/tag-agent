# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Be kind, assume good intent, and keep discussions about the work. Report
unacceptable behaviour privately to the maintainers via a
[GitHub Security Advisory](https://github.com/telip007/tag-agent/security/advisories/new)
or by contacting a maintainer directly.
