frozen. This tests representation of the surrounding system prompt, a separate
experimental dimension required by the full-system-prompt objective.

  policy, tool guidelines, environment and project instructions. Baseline with
  standard must remain byte-for-byte equal to the native renderer.

  API tool schemas, tool implementations, loop and generation controls intact.

the intended treatment unapplied. Tests must demonstrate both the rendered
text differences and preservation of API tool specifications in a real loop
request. A native smoke precedes the development experiment. This is a research
wrapper; no production prompt replacement is implied.

unambiguous development tasks and two development models. Labels ending
